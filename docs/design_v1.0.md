## 1. プロジェクト概要

### 1.1 システム名

Ohana Works

### 1.2 目的

保育園運営における職員管理・勤怠管理・シフト管理・給与計算・給与明細配信・各種申請・監査資料管理・行政対応を一体化する、株式会社Ohana専用の保育園バックオフィスERP。

### 1.3 基本方針

- Ohanaの運用に合わせた独自基幹システムとして開発する。
- 職員向けスマホアプリと管理者向けWeb画面を分離する。
- 給与・マイナンバー・銀行口座・社会保険情報などの重要情報は管理者Web側のみで扱う。
- 勤怠はOhana Works独自のQR勤怠システム(初期開発対象)。
- コドモンExcel取込による勤怠計算は行わない。
- PIMSはCSV出力方式(API連携は将来対応)。
- AIは仮判定・警告・確認支援まで。最終確定は必ず管理者が行う。

## 2. システム全体構成

クライアントは3系統。管理者専用スマホアプリは開発しない。

### 2.1 職員スマホアプリ(Flutter / iOS・Android)

全職員共通の1アプリ。ログインユーザーのロールにより管理者メニューを追加表示する(ロールベース表示切替)。

一般機能：お知らせ / 個別連絡 / 勤務交代依頼 / シフト確認 / 給与明細PDF / 災害モード回答 / 登録情報確認 / 住所・電話・口座等の変更申請 / 有給申請(時間単位対応) / 欠勤連絡 / 遅刻・早退申請 / 勤怠用ワンタイムQR表示

管理者モードでも給与・マイナンバー・社会保険/雇用保険・銀行口座・健康診断結果はスマホでは一切扱わない。

### 2.2 iPad勤怠キオスクアプリ(Flutter / iPadOS)

### 2.3 管理者Web画面(Next.js / React)

## 3. 技術方針

- スマホ/iPad：Flutter(単一リポジトリ・flavor分割)
- Web：Next.js / React
- DB：PostgreSQL(Supabase)、認証：Supabase Auth、ファイル：Supabase Storage
- スケジュール処理：Supabase pg_cron + Edge Functions
- プッシュ通知：Firebase Cloud Messaging
- 金額はすべて整数(円)。浮動小数点禁止。
- 時刻はtimestamptz保存。業務日付判定はAsia/Tokyo固定。
- 実打刻・承認済み勤務時間・給与計算結果は分離管理。実打刻は1分単位保存。
- 給与計算結果には入力値・マスタのバージョンをスナップショット保存(過去月の完全再現)。

### 6.7 標準報酬月額

## 9. 勤怠管理(QR勤怠)

### 9.1 端末

各園1台のiPad(キオスクflavor)。端末マスタ(端末ID / 設置施設 / 有効・無効)で管理し、紛失・入替時は即時無効化。

### 9.2 ワンタイムQR(確定仕様)

- サーバー発行の署名付きトークン(JWT等)をQR化。
- **有効期限：8時間**(職員は原則1日1回アプリでQRを表示すれば足りる)。
- **サーバー側で1回使用ごとに消費(single-use)**：打刻に使用されたトークンは使用済みとなり再利用不可。アプリは使用後に自動で新しいトークンを取得・表示する。
- payload：employee_id / 発行日時 / 有効期限 / トークンID(サーバー管理)。
- 払い出し・使用をログに記録(不正打刻調査用)。
- 目的：他者による打刻・スクリーンショット使い回しの防止(single-use消費により担保)。

### 9.3 代替打刻

スマホ非所持・故障・圏外時は、iPad側の「管理者コード入力による代理打刻」機能を使用する。代理打刻は管理者コード保持者の立会いを前提とし、イベントログに記録、管理者確認対象アラートを発報する。

### 9.4 打刻種別

出勤 / 休憩開始 / 休憩終了 / 退勤(施設移動ボタンは採用しない)

### 9.5 オフライン対応

Phase Aでは必須としない。園ネットワーク障害時のローカルキュー(保存→復旧後同期)はPhase Bで追加する。

## 11. 勤務時間エンジン

### 11.1 実打刻と承認済み時間の分離

- actual_clock_in_at / actual_clock_out_at / actual_break_start_at / actual_break_end_at(1分単位)
- approved_work_start_at / approved_work_end_at / approved_break_minutes

### 11.2 丸めルール(会社決定・現行運用維持)

**丸めの適用範囲(重要)**：丸めは**給与算定用の勤務時間(承認済み勤務時間)にのみ**適用する。
**勤怠管理(実打刻の記録・表示・修正・アラート判定・監査)は、すべて1分単位の実打刻データで行う。**
勤怠画面には実打刻(1分単位)と給与算定用時刻(丸め後)を区別して表示する。

給与算定用時刻の丸めルール：

- 出勤：15分単位切り上げ(6:46〜7:00→7:00、7:01〜7:15→7:15)
- 退勤：15分単位切り捨て(18:00〜18:14→18:00)
- 承認済み退勤時刻は実退勤打刻を超えて設定不可。
- ※就業規則との整合・適法性は会社が社労士に確認のうえ運用(32章)。

禁止：実打刻データ(time_punches)そのものを丸めて保存・上書きしてはならない。

### 11.3 休憩(会社決定・現行運用維持)

- 原則60分。実測55〜65分→60分自動認定 / 45〜54分→休憩不足アラート / 66分以上→超過アラート / 44分以下→重大アラート。
- 8時間勤務で休憩不足時は管理者判断(残業扱い / 短縮扱い / その他)。
- 休憩終了漏れのまま退勤→アラート+管理者確認対象。

### 11.4 早出・残業

シフト外勤務は管理者承認がある場合のみ給与対象。未承認はアラート。

### 11.5 深夜労働

基本発生しないが、22:00〜翌5:00の+25%計算ロジックは実装する。深夜労働発生時は管理者確認アラートを発報する。

### 11.6 時間外労働の判定

#### (a) 通常労働時間制(パート・非常勤等)

1. 日：8時間超 → 時間外
2. 週(日曜起算):40時間超 → 時間外(日で計上済み分は除外)

#### (b) 1ヶ月単位変形労働時間制(正社員)

前提(確定仕様)：

- 変形期間：毎月1日〜末日(起算日=毎月1日)
- 週の起算日:日曜日 / 法定休日:日曜日
- 1日の標準所定労働時間:8時間
- 月間シフト確定後のシフト=変形制上の所定労働日・所定労働時間

判定は日→週→月の順、二重計上禁止：

1. **日単位**：その日の所定労働時間を超えた時間(所定8時間以下の日は8時間超)を時間外。
2. **週単位**：その週の所定労働時間を超えた時間(週所定40時間以下の週は40時間超)を時間外。日単位計上分は除外。
   月またぎ週は、起算日曜が当月内にある週のみ週単位判定を行い、またがり部分は月単位判定でカバーする(社労士確認フラグ、32章)。
3. **月単位**：変形期間の実労働合計が法定総枠(40時間×暦日数÷7)を超えた部分。日・週計上分は除外。
   法定総枠は分単位に換算し端数切り捨て(31日月=177時間8分、30日月=171時間25分、28日月=160時間0分、29日月=165時間42分)。

### 11.7 割増率(労基法37条準拠)

| 区分 | 条件 | 割増率 |
|---|---|---|
| 法定時間外 | 11.6の判定による | +25% |
| 法定時間外(月60時間超) | 月の時間外合計60時間超過分 | +50% |
| 深夜 | 22:00〜翌5:00 | +25% |
| 法定休日 | 日曜日の労働 | +35% |

重複：時間外+深夜=+50% / 法定休日+深夜=+60% / 月60h超+深夜=+75% / 法定休日労働に時間外の概念は適用しない(全時間35%)。

## 12. 変形労働時間制・祝日代替土曜勤務(正社員)

### 12.1 基本ルール

- 正社員は月〜金が基本勤務日。土曜勤務を自動的に休日労働として扱ってはならない。
- 祝日がある週は、祝日の勤務予定を同じ週の土曜へ自動振替し「祝日代替土曜勤務」(変形制上の所定労働日・月給内通常勤務)とする。
- 週に祝日が2日以上ある場合も土曜代替は最大1日。残りの祝日は会社所定休日。
- 祝日数=0 → 代替なし / =1 → 土曜に1日作成 / ≥2 → 土曜に1日のみ作成。

### 12.2 代替勤務の時間

振替元(祝日)の所定労働時間数を引き継ぐ。開始・終了時刻は管理者がシフト確定時に設定する。

### 12.3 分散調整

自動作成された祝日代替土曜勤務は、管理者が同一月内の別の土曜へ手動で分散できる(職員A=第1土曜、職員B=第2土曜など)。分散は原則として月間シフト確定前に行う。

### 12.4 月内完結原則

- 祝日代替出勤は月内完結。月をまたぐ自動処理は行わない。
- 月末の祝日で「同じ週の土曜」が翌月になる場合は自動振替せず、管理者確認アラートを発報する。

### 12.5 祝日週の土曜の有給処理

- 職員本人の有給申請に基づき管理者が承認する方式のみ実装する。
- 会社側が一方的に有給へ振り替える処理は行わない。計画的付与を採用する場合は社労士確認後の追加仕様(32章)。
- 有給処理は対象日にシフトが登録されていることを前提とする。

### 12.6 年末年始

年末年始休日(12/29〜1/3)は祝日代替出勤の対象外。固定シフトがあっても土曜代替は自動作成しない。

### 12.7 パートタイム職員の祝日処理

- 祝日代替出勤は作成しない。
- 固定シフトが祝日に該当した場合、その日のシフトは月間個別シフトに反映しない(他の日への自動振替も禁止)。

## 13. シフト管理

### 13.1 基本方針

- 正社員：月間シフト確定後のシフトは変形制上の所定労働日・所定労働時間として扱う。
- パート:シフトは予定として扱い、給与は実勤務ベース。
- シフト未登録日の出勤打刻は勤務として扱い、アラート表示。
- シフトあり・打刻なしはアラート表示(エラー停止しない)。

### 13.2 シフト作成フロー(週単位固定シフト方式)

```text
Excel週単位固定シフト
↓ [シフト表Excelを読み込む]ボタン
内容読込 → 職員名・曜日・勤務時間を仮表示
↓
対象月カレンダーへ自動展開
↓
祝日処理を自動判定(正社員=土曜代替 / パート=シフト非作成)
↓
エラー・警告表示 → 管理者確認
↓
管理者が手作業調整(分散・時刻設定・施設変更等)
↓
月間個別シフト確定(confirmed)
```

### 13.3 シフトExcelフォーマット

- 照合キーは職員番号を必須とする。氏名のみでの確定照合は禁止。
- 必須列:職員番号 / 氏名 / 雇用区分 / 勤務曜日 / 開始時刻 / 終了時刻 / 休憩予定時間 / **勤務施設**(兼務者は曜日ごとに施設が異なるため必須)。

### 13.4 シフト状態管理(確定仕様)

- 状態:draft(下書き) / confirmed(確定)。
- 確定権限:園長・園管理者以上。
- 月間シフトは対象月開始前に確定する。初期設定では前月25日までに翌月分を確定する運用とし、25日時点で未確定の場合は労務管理者へアラート。
- 確定後の変更はやむを得ない場合のみ。変更履歴(変更前後・変更者・承認者・日時・理由・自動/手動区分)を必ず記録。

### 13.5 シフト区分(コード化)

- normal_work:通常勤務
- holiday_substitute_saturday_work:祝日代替土曜勤務
- distributed_holiday_substitute_work:手動分散された祝日代替勤務
- statutory_holiday_work:法定休日労働(日曜)
- non_statutory_holiday_work:法定外休日勤務(土曜等)
- event_work:行事出勤
- paid_leave:有給
- absence:欠勤
- company_holiday:会社所定休日
- national_holiday:国民の祝日
- year_end_new_year_holiday:年末年始休日
- requires_admin_review:管理者確認対象

「休日労働」という曖昧な区分は使用しない。土曜勤務は 祝日代替 / 法定外休日勤務 / 行事出勤 / 管理者確認対象 のいずれかで扱う。

### 13.6 行事出勤(暫定仕様)

- 月間シフト確定前に所定労働日として登録された行事出勤=通常勤務。
- 確定後に追加された行事出勤=管理者確認対象(時間外または法定外休日勤務として扱う可能性)。
- 社労士確認事項(32章)。

### 13.7 勤務交代

依頼→応募/承諾→管理者承認のフロー。承認権限:園長・主任・園管理者以上。履歴保存。

## 16. 給与計算エンジン

### 16.1 入力

承認済み勤務時間 / 職員マスタ / 給与単価マスタ / 手当マスタ / 控除マスタ / 交通費マスタ / 標準報酬月額 / 社会保険料率 / 雇用保険料率 / 源泉所得税表 / 住民税マスタ / 負担金実績 / 借上宿舎本人負担 / 特殊業務手当

### 16.2 常勤(月給制)

```text
月給
＋ 役職手当 ＋ 職務手当 ＋ 資格手当 ＋ 特殊業務手当 ＋ その他手当
＋ 割増賃金(11.7)
＋ 早番手当
＋ 調整手当
＋ 交通費
− 控除(16.8)
＝ 差引支給額
```

欠勤・遅刻・早退控除:

```text
控除単価 = (月給 + 役職手当 + 職務手当) ÷ その月の所定労働時間
控除額 = 控除単価 × 欠勤・遅刻・早退時間数
```

- **その月の所定労働時間 = 確定月間シフトの所定労働時間合計(月ごとに変動)。**
- 端数は従業員有利(控除額は切り捨て)。

### 16.3 非常勤・パート(時給制)

```text
時給 × 承認済み勤務時間(法定内)
＋ 割増賃金(11.7)
＋ 手当 ＋ 早番手当 ＋ 交通費
− 控除
＝ 差引支給額
```

### 16.4 割増賃金の基礎単価

- 月給者:**(月給 + 割増基礎対象手当) ÷ 年平均月間所定労働時間(固定値・年度初めに算定しマスタ登録)**
  ※欠勤控除の分母(16.2=その月の所定)とは異なることに注意。
- 時給者:時給。
- 割増基礎から除外するのは**通勤手当のみ**。役職手当・職務手当・特殊業務手当は基礎に含める。手当マスタの「割増賃金基礎対象」属性で管理。

### 16.5 早番手当

7:00〜8:00の勤務に15分単位で支給:15分125円 / 30分250円 / 45分375円 / 60分500円。複数施設勤務は施設別按分。

### 16.6 交通費

- パート:出勤日数 × 往復交通費。自転車:1日5時間超200円 / 以内100円。
- 正社員:定期代月額固定。
- 同日複数施設勤務でも1日1回。
- **交通費単価は職員×施設(通勤経路)ごとに登録可能**(兼務者対応)。
- 非課税限度額判定に対応(課税・非課税を分けて集計)。

### 16.7 負担金

単価:オハナ300円 / マハロ300円 / ステーション300円 / ハレレア250円。注文表由来の食数×単価を基本所属園の給与から控除し本部口座へ集約。

### 16.8 控除項目

健康保険(標準報酬×料率) / 厚生年金(標準報酬×料率) / 介護保険(40〜64歳) / 雇用保険(賃金総額×料率) / 源泉所得税(甲乙・扶養数・税額表) / 住民税(マスタ月額) / 負担金 / **借上宿舎本人負担金** / その他控除。

保険料の被保険者負担分端数:50銭以下切捨て・50銭超切上げ。

### 16.9 借上宿舎本人負担金(確定仕様)

- 補助上限69,000円(制度マスタで変更可、ハードコード禁止)。実家賃が上限を超える分を本人負担として控除。
- **家賃からの完全自動計算・自動確定は禁止。** 参考本人負担額(=家賃−上限)の自動表示は可。正式控除額は労務管理者以上が職員×対象月ごとに手入力・確認した「給与控除額」。
- 月途中開始・終了時の日割りは自動確定禁止。警告を表示し労務管理者が手入力。
- 給与明細には「借上宿舎本人負担金 ○○円」を表示(0円・対象外は非表示可)。補足は明細備考欄へ。
- 閲覧・登録・変更・削除:労務管理者以上のみ。園長・主任・園管理者・一般職員には本人負担額・物件情報を表示しない。職員本人には明細上の当月控除額のみ表示。
- 登録・変更・削除はイベントログ記録(操作者・対象・前後金額・理由)。給与確定後の変更は再確定を要求。振込実行後の誤りは翌月調整。
- 税務・社会保険上の取扱い(現物給与該当性等)は税理士・社労士確認事項(32章)。控除マスタの属性で課税・報酬算入の扱いを変更可能にする。

### 16.10 特殊業務手当(確定仕様)

- 処遇改善分配等として職員ごと・給与月ごとに手入力する変動支給項目。固定額実装禁止。
- **前月額の自動継続・自動確定は禁止**(前月額の参考表示は可)。毎月、管理者が確認・確定。
- 入力項目:対象職員 / 対象給与月 / 金額 / 支給理由(選択式+その他自由入力、内部管理上は原則必須) / 内部メモ / 明細表示有無 / 明細表示文。
- 一覧形式の複数職員一括入力に対応:全員0円初期化 / 選択職員へ同額一括 / 前月額参考表示 / Excel・CSV一括読込 / プレビュー / 管理者確認後反映。
- 支給理由選択肢:処遇改善手当分配 / 業務負担加算 / 特別業務対応 / 役割加算 / 臨時補助金分配 / その他。
- 明細表示:「特殊業務手当 ○○円」(0円は非表示可)。備考欄に補足可(例:処遇改善手当分配分を含む)。
- 初期属性:課税対象=はい / 社会保険対象=はい / 雇用保険対象=はい / 労働保険賃金対象=はい / 賞与扱い=いいえ / **割増賃金基礎対象=はい** / 固定的賃金=いいえ。属性はマスタで変更可能。
- 入力権限:労務管理者以上(権限ロールマスタで個別付与可)。
- 登録・変更・削除はイベントログ記録。給与確定後の変更は再確定を要求。
- アラート:入力未確認 / 前月支給あり当月0円 / 前月0円当月高額 / 通常範囲超過 / 支給理由未入力 / 確定後変更。前月差が大きい場合は警告(自動修正禁止)。

### 16.11 手当マスタの共通属性

課税対象 / 社会保険対象 / 雇用保険対象 / 労働保険賃金対象 / 固定的賃金 / 賞与扱い / 施設別按分対象 / 割増賃金基礎対象

### 16.12 給与明細備考と内部メモ

- 職員向け備考:本人の支給額に影響する調整のみ表示(例:退勤打刻漏れ修正分を反映 / 有給2時間使用)。
- 内部メモ:管理者専用(例:6/12退勤打刻漏れ。主任確認済み)。明細には表示しない。

### 16.13 スコープ外

賞与:初期スコープ外(将来Phase D) / 年末調整:スコープ外(税理士対応)。

## 17. 給与確定フロー

### 17.1 締め・支払(確定仕様)

- 締め日:毎月末日 / 支払日:翌月25日(土日祝は前営業日) / 集計期間:1日〜末日。

### 17.2 確定フロー

```text
勤怠確認 → 施設別勤務時間確認 → 残業・早出承認/割増対象時間確認 → 休憩不足確認
→ 交通費確認 → 負担金確認 → 借上宿舎本人負担金確認 → 特殊業務手当確認
→ その他手当・控除確認 → 標準報酬月額・社保・雇保・税確認 → 給与確定
→ 振込CSVまたは振込一覧PDF出力 → 給与明細PDF発行 → 支払日朝8時に職員アプリへ通知
```

給与確定前チェック(AI/バリデーション)に以下を含める:標準報酬月額未登録 / 扶養・税区分未登録 / 借上宿舎利用者の本人負担額未登録 / 特殊業務手当の未確認・支給理由未入力・前月比大差 / 月間所定労働時間の法定総枠超過。

### 17.3 通知

支払日(翌月25日、土日祝は前営業日)の朝8:00に配信。休日カレンダーマスタ+pg_cron+Edge Functionsで予約送信。配信失敗はリトライし状況を管理画面に表示。

### 17.4 確定後の修正

- 原則翌月調整。振込実行前は 確定解除→修正→再確定→再出力 が可能。
- 給与確定単位に「振込実行済み」フラグを持ち、実行済みは再確定禁止。
- 確定ロック解除権限:システム最高管理者のみ。
- 旧給与明細は職員向け履歴に残さないが内部保管(監査証跡)。再確定履歴はイベントログに記録。

## 33. Claude Codeへの禁止事項(統合版)

### 労働時間・シフト

- 変形労働時間制を不採用前提で実装してはならない
- 土曜日勤務を自動的に法定休日労働(35%)として扱ってはならない
- 正社員の祝日シフトを単純削除して終わってはならない(原則同週土曜へ自動振替)
- 祝日2日以上の週に2日分以上の土曜代替出勤を自動作成してはならない
- パート職員の祝日シフトを月間シフトへ作成してはならない/代替出勤を作成してはならない
- 祝日代替勤務の月またぎ自動処理をしてはならない
- 日・週・月の時間外を二重計上してはならない
- 会社側が一方的に有給へ振り替える仕様にしてはならない
- 実打刻データ(time_punches)を丸めて保存・上書きしてはならない(丸めは給与算定用の承認済み時間のみ)

### 給与・控除・手当

- 借上宿舎本人負担額を家賃から完全自動計算して確定してはならない
- 月途中開始・終了時に自動日割り確定してはならない
- 借上宿舎本人負担額・物件情報を労務管理者未満の権限者へ表示してはならない
- 特殊業務手当を固定額として実装してはならない
- 特殊業務手当を前月から自動継続して確定してはならない
- 変更履歴を残さず上書きしてはならない
- 給与確定後の変更を再確定なしで反映してはならない
- 振込実行済みの給与を再確定してはならない
- 金額に浮動小数点を使用してはならない

### 取込・マスタ

- 外部サイト自動取得のみを前提にしてはならない(手動読込を必ず併設)
- PDF/Excel解析結果を管理者確認なしで確定してはならない
- 取得失敗時に給与計算が停止する設計にしてはならない
- 氏名のみでの職員照合を確定に使ってはならない(職員番号必須)
- 補助上限額69,000円等の制度値をハードコードしてはならない

### AI・全般

- AIによる自動修正・自動確定をしてはならない(警告・提案・仮判定まで)

## 34. 最低限のテストケース

### 変形労働時間制・時間外判定

1. 祝日1日の週:土曜代替1日が自動作成される
2. 祝日2日の週:土曜代替は1日のみ、残り1日は会社所定休日
3. 祝日なしの週:代替が作成されない
4. パート:祝日の固定シフトが月間シフトに反映されない・代替が作られない
5. 分散調整:第1週の代替を第2週土曜へ移動(週6日勤務化)しても、月間総枠内なら時間外ゼロ
6. 月間実労働が法定総枠(31日月=177時間8分)を超過した分だけ月単位時間外になる
7. 日所定8時間の日に9時間勤務→1時間が日単位時間外(25%)
8. 日曜勤務→全時間35%(時間外の概念を適用しない)
9. 22時超勤務→深夜25%加算+管理者確認アラート
10. 月60時間超の時間外→超過分50%

### 給与計算

11. 割増単価:年平均月間所定で除した単価になっている(その月の所定ではない)
12. 欠勤控除:その月の確定シフト所定合計で除している
13. 特殊業務手当が割増基礎に含まれている
14. 通勤手当が割増基礎から除外されている
15. 標準報酬月額の適用開始年月に基づき正しい月額で社保計算される
16. 甲欄・扶養2人 / 乙欄 それぞれで源泉税額が正しく引ける
17. 介護保険:40歳到達月から控除開始される

### 借上宿舎

18. 家賃69,000円→本人負担0円(控除非表示)
19. 家賃80,000円・手入力11,000円→控除11,000円
20. 家賃80,000円・手入力10,000円→控除10,000円(参考額と異なる手入力が優先)
21. 月途中開始→警告表示・自動日割りしない
22. 利用終了後に控除が残存→アラート
23. 給与確定後に控除額変更→再確定要求

### 特殊業務手当

24. 当月0円(明細非表示) / 当月10,000円 / 職員ごとに異なる金額
25. 前月10,000円→当月50,000円で警告(自動修正しない)
26. 支給理由未入力で確定前チェックに引っかかる
27. 課税・社保・雇保・労働保険賃金集計へ反映される

### 勤怠・QR

28. トークン使用後に再利用不可(same tokenの2回目打刻が拒否される)
29. 8時間経過後のトークンが拒否される
30. 出勤施設≠退勤施設→管理者調整対象になる
31. 複数施設で重複しない打刻→施設別セグメントが自動生成される
32. 代理打刻がイベントログに記録されアラートが出る

### シフト・確定

33. 前月25日時点で未確定→労務管理者アラート
34. 確定後のシフト変更に理由必須・履歴記録
35. 給与確定→解除(システム最高管理者)→修正→再確定→再出力
36. 振込実行済みフラグONで再確定が拒否される
