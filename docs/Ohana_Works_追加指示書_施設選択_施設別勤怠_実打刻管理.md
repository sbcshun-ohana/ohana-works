## 1. 管理者Web画面: 施設選択フィルター

### 1.1 基本方針

管理者Webの勤怠関連画面には施設選択プルダウンを設置する。

選択肢:
- 大和オハナ保育園
- BABY MAHALO
- Halelea
- Mahalo Station
- 全体

### 1.2 権限による選択肢の制限

- 園長・主任・園管理者: 自身の管理対象施設のみ選択可能(「全体」は選択不可)
- 労務管理者・システム最高管理者: 全施設および「全体」を選択可能

管理対象施設の判定は employee_office_assignments / employee_roles の管理範囲に基づく。
プルダウンの選択肢自体を権限に応じて出し分けること(選べない施設は表示しない)。

## 2. 複数施設勤務者の勤怠管理

### 2.1 基本方針

勤怠履歴は勤務した施設ごとに独立管理する(attendance_segments の office_id 単位)。

### 2.2 管理画面の表示

- 施設選択時: その施設で勤務した勤怠のみ表示する。
- 「全体」選択時のみ: 全施設の勤怠を表示する。

### 2.3 月間勤怠Excel出力

勤務した施設ごとにシートを作成する。

例) 高木太郎が 大和オハナ保育園 / BABY MAHALO / Mahalo Station で勤務した場合:
- シート「高木太郎(大和オハナ保育園)」
- シート「高木太郎(BABY MAHALO)」
- シート「高木太郎(Mahalo Station)」

ルール:
- シート数 = その職員がその月に勤務した施設数
- 勤務していない施設のシートは作成しない
- 各シートにはその施設で勤務した勤怠のみ表示する

各シートの表示項目:
日付 / 曜日 / シフト開始・終了 / 実出勤時刻 / 承認済み出勤時刻 / 実退勤時刻 / 承認済み退勤時刻 / 休憩開始 / 休憩終了 / 実休憩時間 / 承認済み休憩時間 / 実労働時間 / 給与計算対象時間 / 有給 / 欠勤 / 遅刻 / 早退 / 時間外 / 勤務区分 / アラート / 備考

## 3. 実打刻時刻と給与算定時刻の分離(画面仕様)

### 3.1 基本方針

実打刻時刻と、給与計算に使用する承認済み勤務時刻は完全に分離して管理する
(v1.0 11.1〜11.2章の通り。DBは既に分離済み: time_punches / daily_attendances の実測値・承認値)。

### 3.2 月間勤怠画面の必須表示項目

月間勤怠画面では必ず以下の4項目を並べて表示する。

- 実出勤時刻
- 承認済み出勤時刻
- 実退勤時刻
- 承認済み退勤時刻

### 3.3 修正権限(v1.0未確定事項の確定)

実打刻・承認済み勤務時刻は、以下の権限者が個別に修正できる。

- 主任
- 園管理者
- 園長
- 労務管理者
- システム最高管理者

修正時は必ずイベントログ(event_logs)へ記録する
(操作者 / 対象職員 / 対象日 / 修正項目 / 変更前後の値 / 理由)。

---

## 4. Claude Codeへの禁止事項(本仕様分)

- 実打刻時刻を丸めて保存してはならない。
- 給与計算に実打刻時刻を使用してはならない(必ず承認済み勤務時刻を使用する)。
- 実打刻と承認済み勤務時刻を同一項目(同一カラム・同一表示欄)で管理してはならない。
- 勤務施設が異なる勤怠を1つのExcelシートへ統合してはならない。
- 権限のないロールに施設選択プルダウンで管理対象外の施設や「全体」を表示してはならない。
- 打刻修正をイベントログ記録なしで反映してはならない。
