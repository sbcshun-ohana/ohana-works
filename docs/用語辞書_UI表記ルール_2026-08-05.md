本ドキュメントは Ohana Works 各アプリ（admin_web / Ohana Kids(iPad) / parent_app）で
使用する UI 上の表記を統一・整理するためのもの。表記のゆれや「不統一に見えるが意図的な使い分け」を明記する。

## デイリーボードの登園状況ステータス（`present` 状態の表記）

`present`（登園して在籍中の状態）の画面表記は、**閲覧者によって意図的に使い分ける**。

| 対象UI | 表記 | 実装箇所 |
|---|---|---|
| admin_web（職員向け） | **登園中** | `admin_web/src/lib/types.ts` `DAILY_BOARD_STATUS_LABELS.present` |
| Ohana Kids / iPad（職員向け） | **登園中** | `lib/models/guardian_app.dart` `dailyBoardStatusLabel('present')` |
| parent_app（保護者向け） | **在園中** | `parent_app/lib/models/linked_child.dart` `childStatusLabel('present')` |

### 理由（なぜ使い分けるか）
- **職員向けUI = 「登園中」**: 現場職員にとっては「今、園に登園して在籍している」状態を端的に示す「登園中」が直感的。デイリーボードの集計タブ・行ステータスとも用語を統一する。
- **保護者向けUI = 「在園中」**: 保護者に「登園中」と表示すると、「（今まさに）通園・移動している最中」と誤読されうる。保護者には「園に在園している」＝「在園中」の方が誤解が少ない。

> ⚠️ これは**意図した使い分け**であり、表記の不統一・取りこぼしではない。
> parent_app の `present` を「登園中」に変更しないこと。
> 逆に admin_web / Ohana Kids の `present` を「在園中」に戻さないこと。

### その他の登園状況ステータス（全UI共通）
| status | 表記（全UI共通） |
|---|---|
| `not_arrived` | 未登園 |
| `present` | 登園中（職員向け） / 在園中（保護者向け） |
| `picked_up` | 降園済み |
| `absent` | 欠席 |
