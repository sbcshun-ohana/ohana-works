## B. 大原利奈の統括園長への切替(**§A とは分離。お知らせ承認フローが本番に入る段階で実行**)

理由: 本番の権限が「大和のみ」→「全施設」に変わる操作のため、マイグレーション適用とは別立て。実行は俊さんの承認後。

### B.1 手動SQL(本番。employee_number で解決し、固有IDを直書きしない)
```sql
-- 1) 現状確認(大原=employee_number 0001・director・大和スコープ を想定)
select e.employee_number, e.name, r.code as role_code, o.name as scoped_office
from employees e
join employee_roles er on er.employee_id = e.id
join roles r on r.id = er.role_id
left join offices o on o.id = er.office_id
where e.employee_number = '0001'
order by r.sort_order;

-- 2) executive_director を全施設(office_id=null)で付与(冪等)
insert into employee_roles (employee_id, role_id, office_id)
select e.id, r.id, null
from employees e, roles r
where e.employee_number = '0001' and r.code = 'executive_director'
  and not exists (
    select 1 from employee_roles er
    where er.employee_id = e.id and er.role_id = r.id and er.office_id is null
  );

-- 3) 旧 director(大和スコープ)の行を削除して大和の園長を空席化
--    (統括園長が包含するため機能上は残置でも無害。空席化する場合のみ実行)
delete from employee_roles er
using employees e, roles r, offices o
where er.employee_id = e.id and er.role_id = r.id and er.office_id = o.id
  and e.employee_number = '0001' and r.code = 'director' and o.name = '大和オハナ保育園';

-- 4) 切替後の確認(大原の役職が executive_director になっていること)
select r.code, er.office_id
from employees e join employee_roles er on er.employee_id = e.id join roles r on r.id = er.role_id
where e.employee_number = '0001';
```
